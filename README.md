# Побег из лаборатории (Lab Escape)

**Побег из лаборатории** — это динамичный 2D-платформер, разработанный на языке Python с использованием библиотеки [Arcade](https://api.arcade.academy/). Игрок берет на себя роль персонажа, пытающегося выбраться из секретного научного комплекса, преодолевая препятствия, сражаясь с врагами и собирая очки.

##  Особенности игры

*   **Три уникальных уровня**: Каждый уровень представляет собой отдельную зону лаборатории («Центральный блок», «Технические тоннели» и «Сектор Омега») с возрастающей сложностью.
*   **Система стрельбы**: Игрок может отбиваться от врагов, используя лазерное оружие.
*   **Разнообразные враги**: Противники (зомби) обладают базовым интеллектом: они патрулируют платформы и начинают преследовать игрока, если тот оказывается в радиусе видимости.
*   **Ловушки и препятствия**: Уровни наполнены шипами, платформами и сложным ландшафтом.
*   **Сохранение статистики**: Игра автоматически сохраняет результаты прохождения (время, очки, количество убитых врагов) в локальную базу данных SQLite.
*   **Визуальные эффекты**: Использование системы частиц для создания взрывов и праздничного конфетти при победе.

##  Управление

| Действие | Клавиши                      |
| :--- |:-----------------------------|
| **Движение влево** | `A` или `Стрелка влево`      |
| **Движение вправо** | `D` или `Стрелка вправо`     |
| **Прыжок** | `Пробел` или `Стрелка вверх` |
| **Стрельба** | `Левая кнопка мыши (ЛКМ)`    |

## Технический стек

*   **Язык**: Python 3.x
*   **Графический движок**: Arcade
*   **База данных**: SQLite3 (для хранения игровой статистики)
*   **Архитектура**: Проект разделен на модули (виды/экраны, игровые объекты, логика уровней, работа с данными).

##  Структура проекта

```text
YaLyc_Lab-Escape/
├── main.py              # Точка входа в игру
├── player.py            # Класс игрока и его логика
├── enemy.py             # Логика поведения врагов
├── bullet.py            # Управление снарядами
├── level.py             # Конфигурация и генерация уровней
├── camera.py            # Логика следования камеры
├── effects.py           # Система визуальных эффектов
├── data/
│   └── database.py      # Работа с SQLite базой данных
└── views/
    ├── menu_view.py     # Главное меню
    ├── game_view.py     # Основной игровой процесс
    └── game_over_view.py # Экран завершения игры
```

##  Установка и запуск

1.  Убедитесь, что у вас установлен Python версии 3.8 или выше.
2.  Установите необходимые зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите игру:
    ```bash
    python main.py
    ```

##  Статистика
После завершения игры вы можете просмотреть подробный отчет о своих достижениях, нажав кнопку **«Полный отчет»** на финальном экране. Игра сравнит ваш текущий результат со средним показателем всех предыдущих сессий.
